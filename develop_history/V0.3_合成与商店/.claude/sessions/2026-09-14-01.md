## 验收手法：**离线渲染台**（比会话 43 那版省事，下次照抄）

会话 43/44 那版是「把 `admin.js`/`admin.css` 拷进 scratchpad + 手搓 `cat.json`
+ 一个 `lab.html` 把 `fetch` 挡掉」。这次发现**根本不用拆**：

```python
sys.path.insert(0, r"D:\git\popshot-reborn\main\server")
import shopcfg, account_store, databackup
from web import server as websrv

shopcfg.DATA_DIR = 临时目录            # 真的 server/data 一个字节不碰
shopcfg.ensure_files()
accounts = account_store.AccountStore(临时目录/accounts.json)
backup   = databackup.BackupService(config_path=临时目录/server.config,
                                    accounts=accounts, log=print)
httpd = websrv.make_server(27931, accounts, host="127.0.0.1", backup=backup)
httpd.RequestHandlerClass._admin_identity = \
    lambda self: ("lab", account_store.ADMIN_ROLE_SYSTEM)   # ← 免登录
httpd.serve_forever()
```

**整个 `/admin` 都是真的**（真接口、真校验、真三方合并、真保存），只有
「登没登录」被猴补掉了。⇒ 版式、联动、保存回执、冲突提示全能在浏览器面板里点。
⚠ 两个坑：① `sys.path` 要指到 **`server/`** 而不是仓库根（那些模块互相之间是
按顶层模块 import 的，`from server import shopcfg` 会在 `import shopdata` 上炸）；
② 不传 `backup=` 的话「数据备份」那一页回「备份功能没有启动」，那一页验不了。

脚本在 scratchpad（`lab.py`，30 行），**没进仓库**。

## ★★ 用户当场推翻的第一版：紫棠 + 擅自改了那句话的颜色

我第一版新起了一个紫棠 `--edit`，**还顺手把工具条上那句「有未保存的修改」
也从绯红改成了紫**（想让它当图例）。用户两条都否了：「紫色太难看，而且我也
没让你改那句话的颜色，谁让你擅自改的」⇒ 现在是**绯红边框 + 一圈发光**，
那句话原样不动。两条教训写进 **D115①**，比颜色本身重要：

* **没被要求的东西不要顺手改**，哪怕你觉得是配套的 —— 要改先问。
* 「绯红被 `.bad` 占着」那条理由**站不住**：`.bad` 本来就多一层粉底 +
  `flash` 动画，靠底色就分得开。判断「这个色位被占了」之前，先看清它到底
  靠**几样**东西在表意。

## 两个当场改掉的设计问题（都是看了真像素才发现的）

1. **加成系数那一格是整行宽的壳**（1221px），内描边会拉出一条横贯整页的红线
   ⇒ 改成标它里面那个输入框。
2. **称号卡片关着的行整行 `opacity: .55`**，边框跟着一起淡 —— 而「把这张关掉」
   正是这一页最常做的那一改 ⇒ `.card-row.off.edited` 换深一档的红、光加厚。
   ★ 顺手发现旁边那条 `.card-row.off .toggle { opacity: 1 }` **一直是句空话**
   （`opacity` 是整棵子树一起合成的，子元素写 `opacity: 1` 救不回来）。
   没动它 —— 它不碍事，改了反而会让「关着的行」看上去变了样。
