# 会话 03 · 2026-09-16 —— 去卡希尔化：锤子 + 冲刺攻击

## 用户给的两条实机反馈

1. 「艾琳模型会拿着和卡希尔一样的锤子，这个艾琳不需要，请删掉。」（附房间截图）
2. 「冲刺攻击时，艾琳用的是和卡希尔一样的动作，但是手上没有卡希尔的小熊，看起来有点奇怪，
   希望把近身攻击动作改成和瓦尔基里的一样。」

顺带确认：**进游戏正常、武器模型正常**（= 上一轮的 V7 / V8 通过）。

## 怎么定位到「锤子」的

截图只有 30 px 大，先后排除了「泰迪熊」「酒瓶」「宝箱炮」「新步枪」。真正管用的两步：

1. 把爱琳默认套 + 各个候选件蒙皮到 `Stand00` f0 渲出来，逐个和截图比 ——
   `ch03J0000` 挂上去后**和截图逐像素对上**（橙黄大锤，右手，腰高）。
2. `for d in Models/Characters/*/; do ...` 数一遍 `J` 件：**16 个目录只有 ch01 有**。

⇒ 结论写进 §21。教训记进 PROGRESS 第 7 句：「克隆自卡希尔」≠「卡希尔有的她都该有」。

## 冲刺攻击的根因

`[ch01-dash]` **没写** `WMeshIdx` ⇒ 默认取 0 号网格 = `ch01W0000` = 泰迪熊；
`[ch03-dash]` 写的是 `WMeshIdx=-1`（空手），ch00 / ch02 / ch101 / ch102 也都是 `-1`。
⇒ 卡希尔是**唯一**有专属冲刺武器的角色，爱琳照搬她的 `Dash00` 就成了「抱空气」。

顺手捞到两条：她 `ChrProps` 里的 `Dash00-*` 是**自己的一套**（`Bip01_R_Finger1` 打人、
`TotalFrame=31`），而 `Effects/CH03/WP00/Efx/` 里**原版就发了**她自己的花瓣冲刺特效
（挂 `Bip01_R_Hand`）—— 克隆来的 CH01 版挂在熊骨 `Bone_Wp00_11` 上。

## 第二批（用户验收 V11 后又给了两条）

3. 「剩下的格斗特效也改成艾琳的。」
4. 「跑步动作好像还是拿着一个什么东西一样，左右手摆动幅度不一样。」

**特效**：`EVN_EFX_REMAP` 从「按动作分组」改成**一张全局路径映射表**（D13）。
名单不是猜的 —— 把母本 61 个 `.evn` 引用的 24 个特效逐个去 `Effects/` 找 CH03 版，有就换、没有就留，
得到 16 条，落到 21 个 `.evn` 上。踩到两个坑：`CH01_MutuDust` 的 CH03 版多个 `00` 后缀；
`Jab00` / `DashAttack01..05` / `Dash04` / `Dash-B04` **没有** CH03 版（无脑替换会造死引用）。

**跑步**：先把 16 个角色的 `Run-F00` 逐个量了一遍（左右上臂 / 前臂摆幅、手前后行程、
「同侧手·同侧脚前后位移内积」），才发现：
- 卡希尔那套是给泰迪熊编的，「手·脚」只有 **−0.31**（真人跑步应该接近 −1）；
- **瓦尔基里是全表最差**（左右上臂 78.3 vs 16.5）—— 前两轮都从她移植，这次不能；
- ch00 泰尔最合适：同为 `DisplayHeight=75`、前臂摆幅左右恰好相等、手脚反相 −0.81。

试过但不行：**把左臂镜像给右臂**（不换源只修对称）—— Biped 左右骨的局部旋转没有干净的镜像关系，
恒等 / 翻 yz / 翻 xw 三种猜法误差都在 0.28~1.24，没有一种接近 0。

★ 光抄旋转还不够：两套循环起点差约 1/8 周期，直接抄手比脚慢半拍（−0.66）。
加了 `leg_sync_phase()` —— **把一个周期在帧格上试一遍，取「手·脚」最负的偏移**（实测 −3 帧 ⇒ −0.97）。
写成算的而不是常数，是因为铁律 10：换源、母本改了，常数就错，而且错得没提示。

## 第三批（V10 / V12 / V13 验收通过后）

5. 「3 号武器的音效和卡希尔的一样，艾琳没有自带的音效吗」

**先回答问题**：没有。对着 `main/Pack_decrypt/`（原版解密树）逐目录数 ——
`CharacterChanger/ch003.ogg` 是她在整个客户端里**唯一**的原生音，
`FX/wp/`、`FX/wplite/`、`FX/char/KR/char/`、`FX/char/KR/voice/` 四个目录里**一个 ch03 都没有**（§24）。

**再修**：3 号原先借卡希尔的 `ch01@Attack03.ogg`（火箭炮）—— 卡希尔就在旁边打，一听就是同一发。
按铁律 13 先在音频池里搜了一遍孤儿（没有任何 ini / evn / efx / exe 引用的），
捞到 `FX/wp/common/weapon@watergun.ogg`：**`FX/wp/common/` 整个目录就这一个文件，而且没人用**。

用 ffmpeg 解码量了客观特征来确认不是瞎猜：0.51 s（对 `ReloadTime=5300` 的单发慢抛正好，
卡希尔那 1.53 s 会拖进装填）、低频占比 11%（不是炮）、起音 0.021 s、质心 2767 Hz。
「水枪」也正对她发射的 포션（药水）。
